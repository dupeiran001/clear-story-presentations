# 05 — Editorial visual design for presentations

Visual design should make **relationships, hierarchy and intent** easier to perceive. It must look authored for *this particular subject*, not generated by averaging slide templates. Beauty without communicative purpose is decoration.

## Define visual identity through content

Before layouts, decide and record:

1. **Audience and tone:** calm scientific, decisive executive, exploratory workshop, elegant keynote, etc.
2. **Color foundation:** neutral page/text, one semantic primary accent and at most a few secondary codes. Do not default to tech-purple/blue gradients.
3. **Typography roles:** title, body, quantitative/label, footnote. Use robust system fonts if portability matters.
4. **Grid and whitespace:** baseline, margins, alignment anchors and scale. Asymmetry can be deliberate; randomness cannot.
5. **Information motif:** an actual shape from subject matter (signal trace, map, node link, timeline), not an arbitrary accent line or pill.
6. **Imagery/diagram treatment:** vector diagrams, real photos, annotated screenshots, direct labels; consistent lineweight and contrast.
7. **Avoid list:** the specific default clichés to disallow in this deck.

A design system constrains visual behavior; **slide compositions still vary**. Do not require every slide to have title + 3 cards + footer.

## Visual hierarchy

At 2–3 seconds glance, viewer should detect: **what is this about? → what matters? → where should I look? → what supports it?**

Techniques: scale, weight, placement, negative space, contrast, proximity, enclosure, annotation and repetition. If everything is bold or brightly colored, nothing is prioritized.

Use one dominant focal point per moment. Dense charts can be excellent when viewers are given a route through them; a visually empty slide can be poor if it says nothing.

## Type and projection

- Use legible, familiar, available fonts, or appropriately embedded fonts when supported; avoid exotic fonts that cause substitution.
- Prefer clear hierarchy and natural line breaks over all-caps shouting, excessively tight tracking or arbitrary accent colors.
- Common presentation *starting points*, not hard standards: 16:9 canvas, title ~28–40 pt, main text ~22–30 pt, chart labels ~16–22 pt, source notes as small as readable at the actual venue. In a giant auditorium or streaming thumbnail, adjust upward.
- If content will only fit at illegible sizes, change architecture: split, reveal, zoom, simplify, or move reference details to appendices.
- Consider W3C WCAG 2.2 contrast guidance as a baseline for text/background: 4.5:1 for normal text, 3:1 for large text; projection conditions can require higher practical contrast.

## Intentional layout repertoire

| Communicative job | Useful composition | Avoid |
|---|---|---|
| Big claim | one strong sentence + proof anchor | giant ungrounded slogan |
| Problem | representative image/case with one annotated contradiction | generic “challenge” icons |
| Comparison | same-scale side-by-side, highlighted difference | uneven visual scales |
| Mechanism | step-wise annotated flow; persistent labels | spaghetti arrows |
| Evidence | strong data plot + takeaway and caveat | pasted dense dashboard |
| Process | timeline, dependency map, state transition | six decorative boxes |
| Trade-off | criteria-based matrix or paired spectrum | superficial pros/cons icons |
| Transition | purposeful visual pause or framing question | empty divider every 2 slides |
| Summary | one visual model + 2–3 earned conclusions | recap of every bullet |
| Next step | explicit owner/action/date if known | vague “What's next?” |

Layout variation follows **function**, not a quota for novel compositions. Consistency in alignment, color semantics and typographic hierarchy should survive variations.

## Real visual sources

- Prefer source-owned figures, verified diagrams, licensed assets, original vector drawings and meaningful screenshots to generic stock art.
- Rebuild unreadable document figures while preserving data, meaning, citations and provenance.
- Use photos when they provide context, specificity, evidence or emotional stakes; avoid ornamental office handshakes and anonymous AI-generated people.
- Icons should encode categories/operations recognizable without tiny labels, not decorate every card.
- Choose dark mode only for good display/environment reasons; dark surfaces are not automatically premium.

## Avoid the recognizable AI-deck signature

Perform a **template smell test**:

- Five consecutive slides use nearly identical three-card structures.
- Every slide has an abstract blurred gradient and tiny pill labels.
- All diagrams are colorful rounded rectangles, regardless of domain.
- Empty, fake-looking charts with invented numerical scales.
- Decorative ribbons, generic stock images, random blobs and emoji icons.
- Every headline is an overconfident aphorism.
- A three-word label sits above a long corporate-sounding sentence on every slide.
- Everything is centered / symmetrically spaced with no deliberate focal hierarchy.

Fix by **reconsidering the information representation**: show the actual mechanism, a true plot, a representative artifact, before/after or well-typeset result. Don't simply swap colors.

## Motion and builds

Use animation when it provides **controlled disclosure, continuity of identity, causal ordering or comparison**. A stable highlighted element should not jump to a different position/color without reason. Avoid busy transitions that take time without helping reasoning. Ensure a PDF/static fallback retains critical meaning.

## Accessibility and room conditions

Check colorblind distinguishability, avoid relying on red/green alone, label directly and/or use shape/pattern. Use sufficient contrast, consistent reading order, descriptive image context, accessible alt text where supported, and captions for video. Verify on actual aspect ratio and projected/streamed scale rather than only on a laptop editor.

## Design critique prompts

- What is the single area of highest contrast? Is it actually the most important?
- Could the visual exist unchanged in an unrelated pitch deck? If so, make it more specific.
- Does the line work/image genuinely add evidence or model structure?
- Where does the audience's eye enter and exit?
- Is color serving stable meaning across all slides?
- What will fail when reduced to a 1280×720 webinar stream?
