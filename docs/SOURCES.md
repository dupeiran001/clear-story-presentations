# Source provenance, attribution, and third-party licensing

This project is an original set of operational instructions and examples. Its [reading library](../references/10-research-library.md) points to research papers, communication guides, design tutorials, and open-source skills whose **ideas informed the workflow**. A link is not a dependency, an endorsement, permission to copy the linked material, or a claim of partnership.

## Source categories

- **Official implementation/specification:** Claude Code documentation, Agent Skills specification, open-source tooling documentation. Use to verify installation and format rules.
- **Research and public communication guidance:** peer-reviewed presentation/visualization papers; academic communication labs; established educational and accessibility guidance. Translate the underlying principle into appropriate, caveated advice.
- **Practitioner heuristics:** storytelling, editorial and visual design books, tutorials, and blog posts. These offer options, not universal scientifically established laws.
- **Third-party Skills and repositories:** inspiration and comparison. Their instructions, code, assets, and licenses are independent from this project.

## Copyright policy

1. Don't package articles, slide templates, logos, photographs, screenshots, diagrams, fonts, datasets or code from third-party sources merely because they are publicly accessible.
2. Link to works rather than reproducing them. Any future copied/modified assets require a documented applicable license and attribution in the same PR.
3. When suggesting a method, distinguish observed evidence, author recommendations, and the Skill's own editorial rules. Avoid claiming a single deck layout is scientifically optimal for everyone.
4. The repository's MIT License covers its **original files only**; it does not relicense the resources listed in the research library.
5. When making external submissions, cite original authors and comply with the venue or company's confidentiality rules.

## Verification status

The listed resources were curated as reference leads; high-impact official documentation and representative third-party repository pages have been independently rechecked during this packaging review. **Not every linked article or current upstream license has been individually audited line-by-line**, and links may change after publication. Do not treat this list as a promise that all linked resources are simultaneously reachable or license-compatible.

If a link breaks, open an issue or a PR containing the old URL, the replacement, and a note on any content changes that affect the recommended technique.
