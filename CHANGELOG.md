# Changelog

All notable changes to this project should be documented here. This project follows a lightweight, human-readable changelog; versions reflect the Skill package, **not verified model-quality levels**.

## [0.1.0] — 2026-10-20

- Initial general-purpose presentation-thinking Skill with audience-first narrative workflow.
- Added 11 focused references for explanation, story, editing, visual evidence, delivery, formats, and production QA.
- Added 9 scenario-based **manual** evaluation prompts and structural validation script.
- Prepared public repository documentation (English/Chinese READMEs), licensing, contribution instructions, worked example, evaluation method, and continuous structural checks.

### Known limitations

- No published side-by-side behavioral evaluation on a live model yet.
- No bundled slide-generation engine or demonstrated PPTX gallery yet.
- Third-party links may change; linked works remain independently licensed.
